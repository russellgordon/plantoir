This site is the course: the schedule, the ideas, the studio practice,
and the expectations behind all of it.

| Folder | Holds | You will use it |
| --- | --- | --- |
| **All Classes** | One page per period — the agenda and what to do next | Every day |
| **Concepts** | The ideas, stated cleanly | After the class that met one |
| **Technique** | Trained movement, and how each form works | Before and after technique classes |
| **Warm-Ups** | The warm-ups we use, and what each is for | When you are leading one |
| **Choreography** | How dances get made | Whenever you are making something |
| **Discussions** | Seminar questions and how to prepare | The night before a seminar |
| **Portfolios** | Your journal, video, and portfolio entries | All semester |
| **Tasks** | Assessed work, with the criteria | Whenever something is due |
| **Tutorials** | Using the site, filming, writing about dance | The first time you need one |
| **Setup** | How the studio runs | Week one |
| **Style** | How the site works | Now |

## How the pieces connect

Class pages are the spine. Each one names the warm-up, the work, and the
cool-down, and links to whatever that period actually consists of. The
backlinks at the bottom of a page show which classes used it.

Content pages end with a **Curriculum connection** — the Ministry
expectations that page addresses, in the Ministry's own words. The site
also builds a coverage map from those links, so you can see what the
course has actually taught.

## Two conventions

- **Concept pages come after the doing.** They assume your body has
  already met the idea.
- **The newest class is on the section landing page.** If you were away,
  start there.
