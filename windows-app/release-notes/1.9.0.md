New in Plantoir 1.9.0

This update brings Windows up to date with what the Mac got in 1.9.0, and adds a few fixes of its own.

BEFORE YOU UPDATE

- Close any preview you have open, and let a scheduled deploy finish, before you install this version by hand. The installer clears out the old website builder as it upgrades, and a preview or a deploy still running will leave you facing a "file in use" message halfway through.
- Deploy each section again to bring the changes to your class websites. A site you deployed earlier keeps working exactly as it did; GeoGebra sketches and the other site changes reach it the next time you deploy it.

NEW

- GeoGebra sketches on your pages. Put a GeoGebra file beside a page, type GeoGebra commands in a block, or name a sketch from geogebra.org, and students get a sketch they can drag and explore, on a page or inside a quiz question, opened with a tap and served from your own class site. The ready-made MPM2D course has one: The Slope-Angle Conjecture. The sketch's credit line appears on screen and in print.
- Text blocks that wrap. Start a block with ```text wrap and long lines wrap at the window's width instead of scrolling sideways; each line keeps its number and continuation lines show a small ellipsis in the margin. Code blocks never wrap.
- Open in Obsidian goes to the page you are looking at. From a section's window, menu or row, Open in Obsidian opens the Markdown file behind the page the preview is showing, and falls back to the vault when it cannot tell. You can also ask the assistant: "open this page in Obsidian".

IMPROVED

- The website builder runs on a newer engine. Your sites look exactly the same. Plantoir also keeps a record of the known weaknesses in the parts it carries, and they were checked for this version.
- A quiz the website reads differently from the way Plantoir read it is now listed among your folder's problems, naming the page and the quiz, instead of appearing only in the build's console.
- When Plantoir runs out of room part way through getting Swift ready for a course's runnable programs, it now says so plainly, instead of showing a blank where the number of gigabytes should be. (Windows)
- Very long lists in the activity record, such as many dated pages at once, are shortened to fit, and the line still says the true number. (Windows)

FIXED

- Lines in Plantoir's console no longer run together. A line that follows a blank line near the start of a run used to be glued to the one before it, in the console, in a saved problem report, and in the box that asks you a question. A question now appears on its own. (Windows)
- The activity record is now complete for a publish made by an outside assistant such as Claude Code or Codex: the pages dated, the pages kept off, the coverage maps and the other things Plantoir normally notes are all recorded, as they already were for a publish made in the window. (Windows)
