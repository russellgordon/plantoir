This page walks through the example course, so you can see how a finished course is put together before you make your own. Follow the steps with Plantoir and Obsidian open.

## In Plantoir's sidebar

1. Add the example course, if you have not yet. [Look around with the example course](page:example-course) has the steps.
2. Look at the sidebar. The example appears as one row, named EXC2O, with two rows under it: Section 1 and Section 2. It is Grade 9 science, taught to two classes.

{{picture:tour-example-course-2}}
alt: Plantoir's sidebar, showing the example as one row with Section 1 and Section 2 under it.

## In Obsidian

1. Select the EXC2O row and choose {{menu:courseOpenInObsidian}}. Obsidian opens, with the example's folders in its file list.
2. Look down the file list. Ten folders hold shared pages: Concepts, Curriculum, Discussions, Exercises, Investigations, Portfolios, Setup, Style, Tasks and Tutorials. Two shared pages, Learning Goals and Help Sessions, sit beside them. Every section's website gets all of these.
3. Find the folder named Media. It is part of the course too.
4. Find the two folders named `section1` and `section2`. Each belongs to one section, and only that section's website gets what is inside.

{{picture:tour-example-course-1}}
alt: Obsidian's file list for the example, with the shared folders above and the section1 and section2 folders below them.

5. Open `section1`. It holds the folder All Classes, the pages Key Links, Private Notes and Scratch Page, and the section's front page. `section2` holds the same set for Section 2.
6. Open All Classes. There are 86 class pages, one for each class, from Unit 1, Day 1 onward.

## The page that explains the shape to students

1. Open the folder Style, then the page How This Site Is Organised. It is written for students, and both sections' websites carry it.
2. Read what it says. There are two kinds of page: class pages, one for each class, and reference pages, which are written once and linked from many class pages. Its diagram shows three class pages that all link to one concept page.

{{picture:tour-example-course-3}}
alt: The page How This Site Is Organised on a section's website, with its diagram of three class pages linking to one concept page.

## Two websites from one course

1. Go back to Plantoir. Select Section 1 in the sidebar and press {{control:previewButton}}. Section 1's website shows in the window.
2. Select Section 2 and press {{control:previewButton}}. This is a second website, made from the same folder of pages. Its colours and its emoji are different, because each section can have a look of its own.

{{picture:tour-example-course-4}}
alt: The websites of Section 1 and Section 2 side by side, each with a look of its own.

The first preview on a {{machine}} takes longer than later ones. [The first preview is slow](page:slow-first-build) says why.

## If it does not work

- **{{menu:courseOpenInObsidian}} is greyed.** Obsidian is not installed on this {{machine}}, or a section's row is selected. With a section selected, use {{menu:sectionOpenInObsidian}} instead.
- **A folder named here is missing from the website's sidebar.** Curriculum and Media are kept out of the website's sidebar on purpose. They are still part of the course.
