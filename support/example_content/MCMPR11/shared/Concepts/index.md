These pages are the clean statement of an idea you have already met — usually in an exploration, a warm-up, or something that went wrong on your screen. The order below is the order the course needs them in, not the order they appear in a textbook. Come here after class, when you want the idea in one place and in plain words.

**Unit 1 — Computational Thinking, Control Flow, and Problem Decomposition**

- [[Variables, Data Types, and Input-Output]] — What a variable actually holds, Python's core types, and why `input()` always hands you text.
- [[Problem Decomposition and Stepwise Refinement]] — Breaking complex tasks down using top-down design and pseudocode.
- [[Control Flow and Conditional Logic]] — Guiding program execution using `if`, `elif`, and `else` statements.
- [[Pair Programming and Working Together]] — The driver/navigator model, and why two people catch more bugs than one.
- [[Designing Test Plans and Automated Assertions]] — Verifying your logic and systematically catching bugs before they reach production.

**Unit 2 — Iteration and Collections**

- [[Definite and Indefinite Iteration]] — Repeating tasks systematically using `for` and `while` loops, and summarizing data with the accumulator pattern.
- [[Lists, Tuples, and Collection Slicing]] — Organizing ordered data in memory and safely extracting what you need.
- [[Searching and Big-O Intuition]] — Why scanning a list gets slower as it grows, and what a dictionary lookup buys you instead.

**Unit 3 — Modularity, Data Models, and Inclusive Design**

- [[Dictionaries and Key-Value Data Models]] — Storing related properties securely using keys instead of numbered indexes.
- [[Functions, Parameter Scope, and Pure Decomposition]] — Writing reusable, isolated blocks of code that follow the LEGB rules and have zero side-effects.
- [[Type Hints, Docstrings, and Interfaces]] — Treating a function's signature as a promise to whoever calls it, including future you.
- [[Reading Documentation and Using Libraries]] — Using Python's standard library instead of rebuilding it, and reading a real function signature.
- [[User Experience, Accessibility, and Inclusive Design]] — Designing software that works gracefully for everyone, guided by WCAG and inclusive principles.

**Unit 4 — Reliability, Architecture, and Ethics**

- [[Organizing a Multi-File Project]] — Splitting a sprawling script into single-responsibility modules.
- [[Defensive Programming and Exception Handling]] — Protecting your program against bad user input and unexpected system failures.
- [[Digital Ethics, Open Source, and User Privacy]] — Understanding data sovereignty, software licenses, and our ethical obligations as developers.
- [[Digital Citizenship, Etiquette, and Online Literacy]] — Citing sources honestly, using AI tools without hollowing out your own learning, and writing like a professional.
