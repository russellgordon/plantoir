## Agenda

1. Standup — criteria on the desk
2. Tutorial: [[From Sketch to Cut File]] — vector lines, the colour
   code, text as paths
3. The test cards: three run on the laser in front of you, one per
   material (about 15 laser minutes). Before we read them, everyone
   predicts which square will cut cleanly (formative)
4. Read the cards together; the winning settings go on the settings
   sheet
5. Desk time: start your cut file at real size
