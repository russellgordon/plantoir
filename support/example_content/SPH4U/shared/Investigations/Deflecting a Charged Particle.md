A charged particle entering a uniform field bends — parabolically in an
electric field, circularly in a magnetic one. This investigation is where
that distinction becomes something you have watched rather than been told.

## Safety

The classroom simulation carries no hazard. If the demonstration tube is
used, it is mine to operate: it runs at several thousand volts.

## Method

Using the simulation:

1. Fire an electron across a uniform ELECTRIC field between plates.
   Record the deflection for three plate voltages.
2. Fire it across a uniform MAGNETIC field. Record the radius of its path
   for three field strengths.
3. In each case, predict the trend algebraically before running it.

## Analysis

1. Why is the electric-field path a parabola and the magnetic-field path
   a circle? Answer in terms of the direction of the force in each case.
2. From your magnetic data, find the charge-to-mass ratio using
   $r = mv/(qB)$. Compare with the accepted value for the electron.
3. A magnetic field does no work on a charge. Explain how that can be
   true when the particle's direction changes so dramatically.
