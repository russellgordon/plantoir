## Four things worth knowing

**Links go both ways.** At the foot of most pages is a list of pages that
link to it — the fastest way to find which class used an idea, or which
task needs a concept.

**Search is fast.** Press `Ctrl`+`K` or `Cmd`+`K` and type. It searches
inside pages, not just titles, so a term you half-remember will find its
page.

**A folded block hides something.** A line with a small arrow opens when
clicked, usually a check-yourself question. Answer first. Reading the
answer feels like learning and is not.

**Field pages get read twice.** Once before we go, once after, and the
"before" reading is not optional — [[Fieldwork Safety]] exists because
things on it have gone wrong to real people.

## If a link does not work yet

A class page appears on the day we reach it. If tomorrow's page is
missing, that is because tomorrow has not happened. Ask if you are unsure.
