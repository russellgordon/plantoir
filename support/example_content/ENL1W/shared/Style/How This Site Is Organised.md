Six folders and a landing page. Once you know what each folder is for,
you can find anything in this course in about four seconds.

## The folders

| Folder | What lives there |
| --- | --- |
| **All Classes** | One page per class, newest first: what we did, and what to do before next time |
| **Reading** | One page per text we read together, with the context you need and the questions we will argue about |
| **Concepts** | The ideas, written down once: theme, voice, point of view, how a sentence works |
| **Tasks** | Everything I mark, with the criteria published before you start |
| **Exercises** | Practice sets with the answers folded away |
| **Discussions** | The questions we argue about, with the positions laid out |
| **Portfolios** | Your journal, and how to show what changed |
| **Tutorials** | How to do a specific thing: annotate, cite, get unstuck |
| **Setup** | How the room runs, marks, and what to bring |

## The landing page

The front page of this site always shows the most recent class. If you
were away, start there and work backwards — every class page links to
everything that class used, so a missed period is a page, not a mystery.

## Why concepts are separate from classes

Because you meet an idea once and need it eleven times. Point of view comes
up at the start of the course in a short story, later in a novel, and later
still in a film. It is explained properly in one place — [[Point of View]] —
and every class that uses it links there.

That also means the class pages can stay short, which is the point of
them: a class page is a plan, not a lesson.

> [!tip] The fastest way to find anything
> Press <kbd>⌘</kbd> + <kbd>K</kbd> (or <kbd>Ctrl</kbd> + <kbd>K</kbd>)
> and type three letters of what you want. Search is faster than
> clicking, always.
