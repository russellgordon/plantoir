The lab provides the machines; you provide the thinking. The list is short.

## Every class

- **A laptop.** Either school-issued or your personal machine.
- **Your charger.** Code drains batteries faster than browsing does.
- **A notebook.** Paper is essential for planning and tracing tables. Planning a program away 
  from the keyboard is a professional habit.
- **Something to write with.**
- **Water.** Stay hydrated while debugging.

## Software on Day One

You do not need to install any special software before the first class. Everything we do in 
the first few days will run right in the browser or using the tools already on your machine. 
We will cover [[Python Environment Setup]] together when the time comes.

> [!tip] Backups save weekends
> Computers fail, and water bottles spill. Have a plan for backing up your code, whether 
> that's a school cloud drive, a USB key, or pushing to a repository. "My laptop died" is 
> a hardware problem; "I lost all my code" is a backup problem.

Forgot something? Borrow from the front desk, return it at the bell, and nobody will make 
it a thing. If equipment is ever a genuine barrier, tell me quietly and we will sort it out.
