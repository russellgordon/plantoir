Each set below follows a concept page — build the idea there first, then
use these questions to make it dependable. Every set names the classwork
it grew out of, every set ramps from gentle to genuinely chewy, and none
of these sets are timed. Ever.

One warning before you start: this is a newsroom, so most of these
questions are judgement calls, and many of them have more than one
defensible answer. The folded answers do not just hand you *an* answer —
they model the reasoning an editor would use to defend one, because
defending a call out loud is the skill you are actually practising.
