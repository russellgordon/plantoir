> [!abstract] At a glance
> **Time:** one class with the spreadsheet. **Pairs.** Two models, one
> real data set.

Build both growth models yourself, then test them against data somebody
actually collected.

## Method

1. In a spreadsheet, build an exponential model: $N_{t+1} = N_t + rN_t$.
   Plot 50 generations.
2. Build a logistic model:
   $N_{t+1} = N_t + rN_t\left(\frac{K - N_t}{K}\right)$. Plot the same
   range.
3. Vary $r$ and $K$ and record what each does to the curve.
4. Fit both to a real data set — yeast in culture, or the Kaibab deer
   record, or reindeer on St Matthew Island.

## Analysis

1. Which model fits your data better, and over which part of the range?
   [[Graphing Data]] has the plotting conventions.
2. St Matthew Island's reindeer overshot and crashed. Neither model
   predicts a crash. What is missing from both?
3. Estimate $K$ from the data. How confident are you, and what would make
   you more so?
4. What does $r$ actually mean biologically, and what would raise it?
