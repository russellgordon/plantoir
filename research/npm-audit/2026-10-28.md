## What was read and measured for each

**undici is BUNDLED into wrangler.** `wrangler-dist/cli.js` (12,487,748
bytes) carries undici 7.24.4 compiled in (`require_undici`, 224 mentions of
`undici@7.24.4`); `node_modules\undici` is the copy miniflare depends on. So
"miniflare is never started" does not settle these: wrangler's own API
requests run on the same undici version. `scripts/deploy.py` runs only
`wrangler pages deploy <folder> --project-name=… --branch=main
--commit-dirty=true`, with `CI=1` and `WRANGLER_SEND_METRICS=false`.

- **GHSA-4w7w-5xrc-9h26** (cache poisoning through cross-origin redirects).
  Affected only with an originless Agent, a shared cache store AND
  `compose(redirect(), cache())`. wrangler's code calls no `.compose(` on a
  dispatcher (the only two in cli.js are the YAML library's) and uses no
  `interceptors.` member. Not reached.
- **GHSA-55wc-3pg8-jfw6** (decompress interceptor with a throwing handler).
  The same grep: no interceptor is composed. Not reached.
- **GHSA-2m5v-pch6-74hx** (a function-valued `tls` option dropped by Agent).
  wrangler's requests go through `fetch` on undici's global dispatcher. It
  installs exactly one of its own, `setGlobalDispatcher(new
  EnvHttpProxyAgent({ noProxy: noProxy || "localhost,127.0.0.1,::1" }))`,
  when `https_proxy`/`HTTPS_PROXY`/`http_proxy`/`HTTP_PROXY` is set. Neither
  that nor the default Agent is given a `tls` option; cli.js has no
  `checkServerIdentity`, and its `tls: true` lines are a Node built-in module
  list. `NODE_EXTRA_CA_CERTS` and `CLOUDFLARE_CA` do not appear. Not reached.
- **GHSA-qrxm-fqhp-jwvm** (crash on a TLS 1.2 renegotiation). TLS 1.3 has no
  renegotiation. Measured from this PC with the runtime's Node 22.23.4
  (`tls.connect`): api.cloudflare.com **TLSv1.3** (TLS_AES_256_GCM_SHA384);
  the same from the runtime's Python 3.11.9 / OpenSSL 3.0.13 and from Git's
  `openssl s_client`. The host also accepts 1.2 when the client caps at it,
  so this holds because Node offers 1.3. Every `pages deploy` request goes to
  `https://api.cloudflare.com/client/v4` (the asset check-missing,
  upload and upsert-hashes calls among them). sparrow.cloudflare.com (metrics, switched off)
  and dash.cloudflare.com also negotiated 1.3. registry.npmjs.org negotiated
  **TLSv1.2**, but wrangler reaches it only through its update check, which
  uses Node's `https` module (`__require("https")` in the bundled
  `update-check`), not undici. Not reached, on that measurement; a forced
  downgrade would need a certificate valid for api.cloudflare.com.
- **GHSA-9fm3-97px-rjf6** (WebSocket PONG buffering). cli.js constructs no
  undici `WebSocket` (`new WebSocket(` and `import_undici*.WebSocket`: no
  match); a deploy opens none. Not reached.
- **GHSA-wx4j-mvgx-mqwp** (satori's SVG escaping). Quartz uses satori only in
  its CustomOgImages emitter. `build_site.py` → `toggle_custom_og_images`
  comments `Plugin.CustomOgImages()` out of `quartz.config.ts` on every build
  unless `--include-social-media-previews` is passed, and neither app passes
  it (`contracts/app-rules.json` lists it among the flags the apps do not
  pass). With the flag, it draws the teacher's own titles, and its SVG goes
  to sharp as a PNG. Exposure: the teacher's build only.
