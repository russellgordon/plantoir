Everything for this course lives here: the schedule, the ideas, the
documents we work from, the assessed work, and the expectations behind all
of it. The course runs about ten weeks, so it is worth ten minutes now to
learn where things are.

The section landing page always shows the most recent class. If you were
away, start there and work backwards.

## Four things worth knowing

**Links go both ways.** At the foot of most pages is a list of the pages
that link to it. That is the fastest way to find which class used an idea
and where a source has been used more than once.

**Search is fast.** Press `Ctrl`+`K` — or `Cmd`+`K` — and type. It
searches inside pages, not only titles, so a term, a section number, or a
phrase you half-remember will find it.

**A folded block hides something.** A line with a small arrow beside it
opens when you click. It usually holds a question you should try first.
Reading an answer feels like learning and mostly is not.

**Curriculum blocks are at the foot of content pages.** Those are the
Ministry expectations that page addresses, in the Ministry's own words.
They are there so you can see what the course is claiming to teach, and
check it.

> [!note] Checkboxes here are yours
> The `- [ ]` lists on these pages can be ticked as you go. Your browser
> keeps the ticks on this computer; nothing is sent anywhere, and the site
> does not know who you are.

## If a link does not work yet

A class page appears on the day we reach it. If tomorrow's page is
missing, that is because tomorrow has not happened yet — not because
something is broken. The same is true of a task page for a unit we have
not started. Ask if you are unsure.

## What this site is not

It is not a place to submit work, and it does not track you. There is no
login, no account, and no record of what you read. If something on here
needs handing in, the task page says where it goes.
