## Agenda

1. Number talk: [[Which One Doesn't Belong]] — four spinners, and a
   defensible argument for each one being the odd one out
2. Random groups: [[The Simulation]] — estimate a probability by
   running the experiment hundreds of times, then meet a question
   theory cannot easily reach
3. Discuss: whose estimate settled down first, and what "settling
   down" actually means when every run gives a different number. This
   is my diagnostic for the unit — what this room already believes
   about randomness decides how much of Days 2 and 3 goes on the idea
   of a distribution before we start using one
4. Name it: [[Random Variables and Distributions]] — the table that
   attaches a probability to every value a variable can take
5. Tool: [[Simulating with Python]] — ten thousand trials in four lines
