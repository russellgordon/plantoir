# Plantoir working folder

This folder holds class websites made with Plantoir. Each course is a folder
under `courses/` (an Obsidian vault of Markdown pages), and each section of a
course has its own website built from it.

Guidance for writing pages lives in skills beside this file. Read the one
that matches the task before writing:

- **Any page at all** - writing, revising or reorganising a lesson, a
  concept page, a class page, a folder's front page or Key Links: every way
  content can be written for the site (callouts, diagrams, tables, maths,
  checklists, success criteria, links, embedding one page in another,
  pictures and PDFs in Media, videos, GeoGebra sketches and PhET, hidden
  pages and `publish:`, folders, class pages and their dates) is in
  `.agents/skills/plantoir-page-authoring/SKILL.md` (the same file is at
  `.claude/skills/plantoir-page-authoring/SKILL.md`). Read it first; it
  says which of the skills below to read as well.
- **Printable pages** - worksheets, handouts, practice sets, answer keys, or
  any page "students will print", or a page that should hand out an existing
  PDF: `.agents/skills/plantoir-printing/SKILL.md` (the same file is at
  `.claude/skills/plantoir-printing/SKILL.md`).
- **Handouts made as a PDF** - "make me a worksheet", a warmup, a review
  sheet, a quiz or test for marks, an answer key or solutions, anything to
  print and hand out, in any course: offer the house style first (a LaTeX
  source, the PDF and its answer key from one file), where the files go,
  and how every answer is checked are in
  `.agents/skills/plantoir-handouts/SKILL.md` (the same file is at
  `.claude/skills/plantoir-handouts/SKILL.md`). It says when a printable
  page is the better fit.
- **Graphs, diagrams and GeoGebra sketches** - a graph of a function (a
  parabola beside its parent, two lines meeting), a geometry or
  similar-triangles figure, a number line, a probability tree, a circuit,
  anything to be "plotted" or "drawn", and a GeoGebra sketch students drag
  or a slider: which fence to write, complete patterns to paste, a
  GeoGebra sketch three ways, and what cannot be done are in
  `.agents/skills/plantoir-math-graphs/SKILL.md` (the same file is at
  `.claude/skills/plantoir-math-graphs/SKILL.md`).
- **Code students run** - "make this example runnable", a Python program
  students edit and run in the browser, a Swift program students run with
  their own input, a program that reads input, "try it yourself": how to
  opt the page in, the ` ```python run ` block and its flags, the
  read-only ` ```swift run ` block, input, and what each language can and
  cannot do are in `.agents/skills/plantoir-runnable-code/SKILL.md` (the
  same file is at `.claude/skills/plantoir-runnable-code/SKILL.md`).
- **Questions students check themselves** - "add a 5-question check", a
  quiz, practice questions, a self-check, an exit ticket, multiple choice,
  fill in the blank: the ` > [!quiz] ` callout for every kind, how answers
  are checked, shuffling, and graphs and code inside questions are in
  `.agents/skills/plantoir-quizzes/SKILL.md` (the same file is at
  `.claude/skills/plantoir-quizzes/SKILL.md`).
