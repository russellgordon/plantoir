WHAT THIS CAN AND CANNOT SAY
  The readers of these four descriptions are outside assistants (Claude Code,
  Codex) over MCP. Neither can be run as a controlled, repeatable routing suite
  on this Mac, so this is a PROXY: the smaller assistant's weights shown the
  whole MCP surface. It can catch a description change that pulls a request
  to the wrong tool or inverts a publish/hide; it cannot say how a frontier
  model reads the text. Windows owes its own run only if its server serves
  different text for these four tools (it serves the contract's text since
  #114), and its local model reads none of them.
