DNA to RNA to protein — the central dogma, with the caveat that it is a
description of information flow, not a law.

## Transcription

RNA polymerase binds a promoter, unwinds the DNA, and builds mRNA from the
template strand. In eukaryotes the transcript is then processed: a 5′ cap,
a poly-A tail, and — most significantly — introns spliced out.

Alternative splicing means one gene can produce several proteins, which is
how about 20 000 human genes make far more than 20 000 proteins.

## Translation and ribosome structure

Translation occurs on ribosomes, complex ribozyme machines composed of a small
subunit (which binds mRNA) and a large subunit (which catalyses peptide bond
formation across three active sites):
- **A site (aminoacyl):** receives the incoming aminoacyl-tRNA matching the codon.
- **P site (peptidyl):** holds the tRNA carrying the growing polypeptide chain.
- **E site (exit):** releases the deacylated tRNA.

Initiation factors assemble the ribosome at the 5′ cap; elongation factors drive
translocation; release factors recognise stop codons (UAA, UAG, UGA) to terminate
synthesis.

## The genetic code

64 codons, 20 amino acids, so the code is redundant — several codons per
amino acid, with the redundancy usually in the third base (wobble hypothesis).
That is not an accident: it means many point mutations change nothing at all.

The code is also nearly universal, which is what makes genetic engineering
work at all: human insulin genes function in bacteria because both read
the same code.
