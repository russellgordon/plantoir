away, start there and work backwards.

## Three things worth knowing

**Links go both ways.** At the bottom of most pages is a list of pages
that link to it — the fastest way to find which class used an idea.

**Search is fast.** Press `Ctrl`+`K` (or `Cmd`+`K`) and type. It
searches inside pages, not just titles.

**A folded block hides something.** A line with a small arrow opens when
clicked, usually a check-yourself question. Try answering first; reading
the answer feels like learning and is not.

> [!note] Checkboxes here are yours
> The `- [ ]` lists can be ticked as you read down them. Your browser
> keeps the ticks on this computer, and the site does not know who you
> are.

## If a link does not work yet

A class page appears the day we reach it. If tomorrow's page is missing,
that is because tomorrow has not happened. Ask if you are unsure.
