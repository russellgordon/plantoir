Plantoir 1.6.0

Plantoir 1.6.0 is for the Mac. Plantoir 1.4.0 or later will offer this update by itself.

Nothing you have already built changes. A page prints as a handout only when you mark it printable; every other page builds exactly as it did before, down to the last byte, and every site you have already deployed stays as it is.

New

  • A page can print as a proper handout. Add printable: true to the settings at the top of a worksheet, review or practice page, and it gains a Print button beside its date.
  • Print offers three choices: Questions only, Answers only, or Both, with the answers starting on a fresh page and numbered separately. Nothing prints until you choose one, and you can choose Portrait or Landscape paper first.
  • The handout looks like a typical typeset worksheet: Latin Modern type, a bold title, questions numbered in the margin with lettered parts set side by side, and a footer with the page's title, the course code and the page number.
  • Answers you write in folded callouts move to the answer key, labelled by the question they belong to. Hints print in place, unfolded.
  • Course Settings has a Printing section: your school's name, the blanks students fill in (Name, Date, Class #), and where the school name and course code print on each page.
  • A page can hand out a PDF you already have instead. Name the file, kept in the course's Media folder, in the page's settings, and Print opens that PDF.
  • Claude, Codex and other assistants are told how to write a page that prints well. Plantoir writes a short guide into your working folder, and if you already keep your own CLAUDE.md or AGENTS.md there, it asks before adding a section to the end, leaving your own words untouched.

Improved

  • Pressing Print in Plantoir's own preview opens the page in your web browser, ready to print.
  • On paper, a handout leaves out buttons, menus and the "click to expand" hints, prints diagrams and pictures whole and in light colours, and prints code in a plain box with line numbers.
  • A worked example keeps its box on paper; nothing else is boxed or shaded.
  • A page's Curriculum connections section never prints, in a handout or from the browser's own Print command, so students see the questions rather than the planning.
  • If any part of a handout would be cut off at the edge of the paper, Plantoir says so and prints nothing, rather than handing you a sheet with words missing.

Plantoir 1.5.0

Plantoir 1.5.0 is for the Mac. Plantoir 1.4.0 or later will offer this update by itself.

New

  • A Course menu and a Section menu in the menu bar hold everything you can do to the course or section you have selected, with keyboard shortcuts shown beside them.
  • Things you used to ask the assistant for are now in the Section menu too: Publish Pages…, Hide Pages…, Publish Class for a Date…, Rebuild Preview, Undo Last Change, Add Next Class, Re-date Classes…, Make Room for Classes… and Class Dates…. Each shows you what it will do before it does it. Right-click a section for the everyday ones.
  • When you deploy, Plantoir asks about class pages students can already see that are dated after your next class. You can hide the ones you tick, or keep them all; tomorrow's class, published the evening before, is never asked about.
  • File ▸ Open Recent lists the working folders you have opened, and it and Open Working Folder… work even when no window is open.
  • Help ▸ Publishing and Deploying… explains the difference between the two, and Help ▸ Plantoir Help opens plantoir.app.
  • Plantoir ▸ Settings has a Deploying tab, which holds your Cloudflare Account ID in one place. Course settings and the New Course panel show it, with an Open Settings… button to change it.

Improved

  • Plantoir follows the Mac's own conventions more closely. Escape closes every sheet, Return presses a sheet's main button only when that button can be used, every sheet's title is the same size and shape, and every text field wears the same border.
  • The Delete key removes the course, section, backup or archive you have selected (after asking), and Remove… now sits at the bottom of each right-click menu.
  • Right-clicking a course or section offers Revise With ▸ Claude…, Codex… or Local AI Assistant…, named the same way as in the menu bar.
  • All Backups can be sorted by course, date made or size, and its rows have a right-click menu.
  • When a backup, restore or deletion goes wrong, the message names what could not be done.

Fixed

  • A failed build is no longer blamed on Netlify limiting deploys just because the number 429 appeared somewhere in its output.
  • The − button under the sidebar can no longer remove a section of a course you keep for reference.
  • Copy a Page can now be closed with Escape.

Plantoir 1.4.5

Plantoir 1.4.5 is for the Mac and for Windows. Plantoir 1.4.0 or later will offer this update by itself.

Improved

  • The first window after an update used to be held back while Plantoir got your folder ready — about two minutes on Windows, a few seconds on a Mac. Now the window appears at once, with a notice that says the folder is being got ready and that Preview and Deploy wait for it. Preview and Deploy are available again the moment it finishes: usually a few seconds on a Mac, 15 to 20 seconds on a typical Windows laptop, and longer on a slow disk.
  • Every text field in Plantoir is now the same height and wears the same border: the New Course panel's fields and the Copy a Page search field matched an older look and were two points shorter than the rest.

Fixed

  • When Claude or Codex rebuilds a preview or publishes a page while that section is being deployed, the answer now says the section is being deployed, so the preview cannot be built until that finishes. Before, it only said the preview could not be built. On a Mac the answer also no longer sends you to "that section's window" when Claude or Codex has no window to look in.
  • An update Plantoir found but could not show at the time — because you kept Plantoir in front all day, or had switched away and quit before coming back — is offered again later the same day, and looked for again the next time Plantoir opens, instead of waiting for tomorrow's check.
  • When Claude or Codex schedules a deploy and names classes like "Unit 2, Day 3", the title is no longer cut in half. Class titles are now separated by semicolons, so a comma inside a title stays where you put it.

Plantoir 1.4.4

Plantoir 1.4.4 is for the Mac. Windows: no changes in this release; the Windows download stays at 1.4.3. Plantoir 1.4.0 or later on a Mac will offer this update by itself.

New

  • Plantoir now says "deploy" for putting your website online and "publish" only for marking a page to be included. The words are kept apart everywhere you read them: in the app, in what the assistant says, in the starter pages a new course comes with, and on plantoir.app, where the Publishing page is now called Deploying (the old address still works).
  • Type "schedule a deploy for tomorrow at 6:30 am" to the assistant and it sets that up for you to agree to; "schedule a deploy" with no time asks you for one and never deploys right away; "cancel that scheduled deploy" cancels it. A request that names a later time is never carried out straight away.
  • "Start a new unit with the next class" and "Add three more days to Unit 2" are answered by the assistant exactly as you say them. A request it cannot be sure about is pointed at the wording that does it, rather than adding a page you did not ask for.
  • A Claude or Codex session opened from Plantoir now keeps hold of the course it was opened from, the way the built-in assistant does: its backup is kept, a second session on the same course is refused, and renaming or restoring the course waits until the session ends.

Improved

  • A deploy no longer starts while that section's scheduled deploy is still working, including one left running after Plantoir was closed. The new deploy waits for it, up to thirty minutes, and tells you if it had to stand down.
  • A scheduled deploy's notification now reads "deployed on its own to …", and says that your website has the new pages.
  • The About window and the plantoir.app card say "Grow a class website."

Fixed

  • The "_DUPLICATE ME" page a new course comes with names its heading marks again: "Every ## (level 2) and ### (level 3) heading…". Courses made before this update keep the page as it was.

Plantoir 1.4.3

This release is for the Mac. The Windows download on plantoir.app remains version 1.4.2 for now. On a Mac, Plantoir 1.4.0 or later will offer this update by itself.

New

  • (Mac) Claude and Codex can change a course while its preview is open. They are asked to wait only while Plantoir is actually building that course's website, for a preview or for a deploy. A change made while a preview is open is saved straight away; press Stop Preview, then Preview, to see it.
  • (Mac) Ask Claude or Codex to deploy a section and the deploy goes ahead even when a preview is open. If that closes the preview, Plantoir says "Closed for a deploy" instead of telling you something went wrong.
  • (Mac) Type "publish unit 4, day 3" to the assistant and it is answered straight away.

Improved

  • When two pages have the same name, asking the assistant to publish one now asks which you meant, naming each with its folder.
  • When making room for extra classes cannot finish every page, Plantoir names the pages to look over before they go on your website.
  • If a change to several pages stops part way, the assistant says plainly that only part of it was made. On the Mac it also points you to Restore Section.
  • A deploy that has to rebuild a website made by a preview explains itself in plainer words.

Fixed

  • (Mac) Adding a section no longer shows a hidden page in the new section when that page's settings were written with quotation marks.
  • (Mac) Hiding or publishing a whole unit, publishing a class by its date, and the links checklist now change the right page when a class page shares its name with another page.
  • Class dates remembered with an impossible year are asked for again instead of being believed.

Plantoir 1.4.2

macOS only: Windows has no changes in this release; the Windows download is still 1.1.0.

New

  • Press Preview when today's class is published but the section's front page still shows an older one, and Plantoir offers to put today's class there. A "Not Today" button leaves things as they are.

Improved

  • In the links checklist, a page that is only reached through another page is listed under it, and a page brought along by a ticked class is shown coming with it. Pages are named by their titles.

Plantoir 1.4.1

macOS only: Windows has no changes in this release; the Windows download on plantoir.app is still 1.1.0.

This release is for the Mac. It makes previewing and deploying more dependable, tidies Course Settings, and adds a checklist for pages that link to pages students cannot see yet. Plantoir 1.4.0 will offer it to you by itself.

New

  • When a page you are publishing links to pages that are hidden, Plantoir shows a checklist in the section window. Tick the pages to publish, each dated like the class that uses it. A hidden class is offered unticked and brings its own pages along. Choosing Not Now publishes nothing.
  • With "This is a club" ticked, the New Course panel says Meetings, Club code, Club name and Create Club.

Improved

  • A preview that has to wait now says what it is waiting for.
  • A section cannot be previewed while that same section is being deployed, whether the deploy came from another window, the assistant or Terminal.
  • Get Ready for the Start of the Year names pages by their titles, and adds a folder only when two pages share a title.
  • Course Settings shows the Class Pages rows only for a course that recorded them, such as a club, and says "Language and region" instead of "Language / region (Quartz locale)".
  • Course Settings' Save button looks disabled when it is, and says why when something holds it back.
  • Every text field now has the same visible border.
  • The details shown under a preview, a deploy or a new course say "website builder", never container or Docker.

Fixed

  • Work left behind by a closed Revise with Claude or Codex session no longer stops previews until the Mac restarts.
  • A deploy you ask Claude or Codex for now stops at a question and tells you to deploy once from Plantoir, instead of waiting for ever.
  • An emoji or grade-in-title setting in Course Settings no longer changes on its own.
  • Copy a Page's checklist, and the screen after it, now fit on the screen however many pages are skipped.
  • The example course's progress bar now reaches every step.
  • Deploying to Cloudflare Pages after its project was deleted there now makes the project again instead of stopping.

Plantoir 1.4.0

This release is for the Mac. It is the biggest one since Plantoir began: Plantoir now keeps itself up to date, the first course on a new Mac starts much sooner, and there is new help for the start of the year, for clubs and for deploying on a schedule.

Before you update

  • This is the last release you install by hand. From 1.4.0 on, Plantoir checks for new versions by itself and asks you before installing one. If you are on 1.3.1 or earlier, download this one yourself; after that, you will not need to.
  • The Mac download is now about 411 MB (it used to be about 60 MB). Plantoir now carries its own copies of the helper programs it used to download the first time it ran, so the first course on a new Mac is ready much sooner. A download this much bigger than you remember is still the right file.
  • A deploy you scheduled before updating still happens as you set it. Until it runs it may appear under a slightly different name than new ones; it can be shown, cancelled and run just as before. Scheduling that section again replaces it.

New

  • Plantoir finds its own new versions, asks before installing them, and never installs one while it is building, previewing or deploying.
  • Get Ready for the Start of the Year… puts every class after the first into draft in one step. You see what will change first, and you can undo it.
  • This is a club in the New Course wizard: weekly meeting pages and a club front page, and the assistant talks about "meetings" rather than classes.
  • A How I Teach page for each course, which Claude and Codex read before helping with it. Open or create it from Course Settings.
  • A course with two curriculum folders gets a coverage map for each, and College Board codes count.
  • Ready-made example content for TAS2O.
  • A deploy set for later tells you how it went in a notification, even when Plantoir is closed. Clicking the notification opens that section.
  • The assistant can answer "What does Unit 2, Day 3 link to?" straight from the page, and "Publish all the classes in Unit 2." publishes the unit.
  • The build warns you when a published class links to pages students cannot see yet.

Improved

  • The first time Plantoir runs on a Mac, it gets the website builder ready in the background, and that first build is smaller and faster.
  • Plantoir reopens on the working folder you used last.
  • Every folder and file list in Course Settings and the New Course wizard is now a table with checkboxes.
  • The Backups list shows how much space each backup takes, and you can delete several at once.
  • The front page, and every page a class links to, show that class's date.
  • A scheduled deploy goes where the course deploys at the time it runs, and every deploy uses the settings as you last saved them.
  • The assistant reads a course's settings when it acts, not when its window was opened.
  • Times the assistant cannot place, such as "deploy at 6:30", are asked about instead of deploying right away. "Publish all of those" asks which pages you mean.
  • Duplicating a class that moves other classes warns you, on its card, that Undo will not move them back.
  • Two working folders that hold the same course each keep their own scheduled deploy.
  • A page whose settings Plantoir cannot read is hidden from students and named in the build, instead of being published or stopping the build.
  • Messages about a working folder say plainly what is wrong, and the first-run messages talk about "your website builder".
  • Clearer wording in several places: skeleton pages no longer show "{subject}", the skeleton choice says "an English skeleton", and the wizard's unit row no longer says "Unit" twice.

Fixed

  • Hide from the site's sidebar now always matches the built site, even with two windows open or a preview running.
  • Unpublishing a class no longer hides another class it links to.
  • Adding a section no longer publishes a page you had hidden.
  • Publishing now follows every way of writing a link — with an escaped |, in angle brackets, or Markdown style — and never follows a link inside code or a %% comment.
  • Pages with unusually written settings are no longer treated as hidden, broken by a restore, or skipped. Moving or renaming a class no longer leaves half a date behind.
  • A scheduled deploy whose build failed no longer names a destination it never reached.
  • A deploy to a folder lands where it says, or tells you it did not. Pressing Cancel during a deploy ends it quietly.
  • Previews: the address is never lost, a Mac that cannot reach the website builder stops within seconds instead of waiting, each working folder finds room for its own previews, and two people on one Mac no longer see each other's previews.
  • The window, the assistant, a scheduled deploy and an outside assistant can no longer build the same course at the same time.
  • A working folder whose name has an accent or different capitals no longer gets a second website builder.
  • Plantoir no longer offers to use a working folder that the website builder cannot reach.
  • Approving a change from the assistant no longer freezes the window while the course is backed up.
  • Copies and imports of a course no longer bring its Obsidian add-ons along.
  • One unreadable character no longer empties a problem report.
  • A course can no longer be called "work", and the folder path shown under a chosen folder now names every folder in it.
  • Four ready-made curriculum explainers no longer link to pages a skeleton course does not have.
