GitHub has a programme for teachers named GitHub Education. GitHub's pages say that it includes GitHub Copilot Pro for teachers GitHub has verified. This page reports what GitHub's pages say, in GitHub's words, and where to apply.

GitHub decides who qualifies and what an account includes. Plantoir does not, and the answer may differ for you. Plantoir does not apply for you, check whether you qualify, or sign you in.

Plantoir needs no assistant, and nothing on this page is needed to use it. See [About the assistants (optional)](page:assistants).

## Who GitHub says can apply

GitHub's page for teachers says:

"To access GitHub Education benefits, you need to be a currently employed educator at an accredited educational institution."

Its instructions for applying list what you need:

- to be an educator, a faculty member or a researcher;
- a school-issued email address that GitHub can verify;
- documents that prove your affiliation with your school, to upload;
- a personal account on GitHub.

> [!note]
> GitHub's pages do not say whether a teacher at a secondary school qualifies. The pages read for this page do not name secondary schools, high schools or K-12 schools, either to include them or to leave them out. GitHub's documentation does speak of "teachers of all levels". Its page for teachers also gives this reason for a refusal:
>
> "If your application was not approved, it may be due to insufficient proof of current academic employment or affiliation with a non-degree granting institution."
>
> A secondary school grants no degrees. So Help cannot tell you whether GitHub will approve a teacher at your school. Applying is how you find out.

## Apply

The steps are GitHub's, from [Apply to GitHub Education as a teacher](https://docs.github.com/en/education/about-github-education/github-education-for-teachers/apply-to-github-education-as-a-teacher). Follow that page if it differs from this one.

1. Sign in to GitHub with your personal account.
2. Go to your Education benefits settings, as GitHub's page directs.
3. Under the heading GitHub Education, click Start an application.
4. Complete the form, then click Submit application.

{{picture:github-education-2}}
alt: GitHub's public instructions for applying to GitHub Education as a teacher.

As proof, GitHub asks for a faculty ID or an employment verification letter. It asks that at least one date showing your current status be clearly visible.

GitHub's pages do not say how long an application takes.

## If GitHub does not approve it

GitHub's page [Why wasn't my application to GitHub Education for teachers approved?](https://docs.github.com/en/education/about-github-education/github-education-for-teachers/why-wasnt-my-application-to-github-education-for-teachers-approved) gives these reasons and what to do.

- **The picture you uploaded does not clearly show your current employment with a school.** Apply again with another picture of your faculty ID or employment verification letter.
- **GitHub has not verified your school's email addresses.** GitHub may ask for more proof. Apply again with a different picture, with at least one date clearly visible.
- **Your school lets alumni and retired faculty keep their email addresses.** GitHub may ask for more proof, in the same way. For questions about the school's addresses, GitHub asks that your school's IT staff contact it.
- **You did not apply as a teacher.** When you apply again, choose Faculty to describe your status.

## Turn on GitHub Copilot Pro

GitHub's pages do not put this the same way everywhere. Its documentation for teachers says:

"A free subscription for GitHub Copilot Pro is available to verified teachers with GitHub Education."

Its page of plans says:

"Verified teachers and maintainers of popular open source projects may be eligible for free access to Copilot Pro."

Its page on GitHub Copilot Pro for teachers adds: "GitHub reevaluates your eligibility every month."

Once GitHub has verified you as a teacher, the steps on [GitHub's page](https://docs.github.com/en/copilot/how-tos/copilot-on-github/set-up-copilot/enable-copilot/set-up-for-teachers-and-os-maintainers) are these.

1. On any page of GitHub, click your profile picture at the upper right, then click Copilot settings.
2. A page titled GitHub Copilot Pro says that you are eligible. Click Get access to GitHub Copilot.
3. Set the policies for how GitHub Copilot is used, then click Save and complete.

## GitHub paused sign-ups for a time

In April 2026 GitHub announced that it was pausing new sign-ups for several of its GitHub Copilot plans. Its announcement to its community said:

"These updates apply across Copilot plans, including Education users."

"When signups resume, you will be able to activate the Education benefit if you are still eligible."

In June 2026 GitHub announced that sign-ups for those plans were reopening gradually. That notice does not mention teachers or GitHub Education. GitHub's pages for teachers, as read for this page, carry no notice of a pause.

So Help cannot tell you whether the benefit can be turned on for your account today. Your Copilot settings on GitHub show what is offered to you.

## If you do not qualify

GitHub's page on GitHub Copilot Pro for teachers names its paid plans. It also names a plan called Copilot Free, which it describes in these words: "to get a limited experience of Copilot without a paid plan".

GitHub's page of plans says that every plan includes the command-line tool. That tool is the part Plantoir opens.

Whether the limits of Copilot Free are enough for work with Plantoir has not been established.

## What else GitHub lists for teachers

GitHub's documentation lists more for a verified teacher. The list includes applying for GitHub Team, an overview of your GitHub Classroom, discussions with other teachers, and events for students.

One thing is left out. GitHub says: "Teachers are not eligible for the partner offers that come with the GitHub Student Developer Pack."
