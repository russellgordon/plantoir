Each page holds one expectation, word for word, including the italic
examples the Ministry prints inside them. Every class page, technique
page, and task in this course links back to the codes it addresses, and
the codes are tags, so every page tagged `#A2` can be gathered in one
place.

> [!note] One inconsistency in the source, reproduced rather than fixed
> The dance overview earlier in the document calls the first strand
> "Creating and Presenting", while the heading printed with this course
> calls it **"Creating, Presenting, and Performing"**. The course pages
> are the authority for a course, so that is the version used here. If
> your department's paperwork says the other one, this is why.

## Why the codes matter more than they look

A code is a shared address. When a student asks "why are we doing this?",
the answer is a link. When a department writes a course outline, or a
teacher takes over a class partway through, the codes are what make one
person's planning legible to another.

## How this course reads them

Strand A is what you make and perform, strand B is what you notice about
it, and strand C is what makes both possible — anatomy, terminology,
context, and safe, responsible practice. C is not a unit; it runs through
every studio period, which is why safety and terminology appear on the
first day and the last.
