The substantial projects of this course: four unit summative tasks and one final evaluation.

A task is not a quiz and it is not a set of exercises. It is a working piece of software, built across several days in class, tested against real constraints, and documented so that somebody else can understand it.

## The Course Tasks

- [[Task 1 - Pacific Trail Route Planner]] — Alpine hazard assessment and Naismith route modeling for BC backcountry expeditions.
- [[Task 2 - Salish Sea Marine Sensor Tracker]] — Telemetry stream processing, moving window statistics, and anomaly detection for Ocean Networks Canada subsea stations.
- [[Task 3 - Indigenous Language Lexicon Engine]] — Dictionary indexing, Unicode diacritic normalization, and Leitner spaced-repetition flashcards for FirstVoices BC language revitalization.
- [[Task 4 - Wildfire Early Warning Dashboard]] — The culminating project: a multi-module emergency management system computing the Canadian Forest Fire Weather Index (FWI) and community Air Quality Health Index (AQHI).
- [[Final Evaluation - Software Portfolio and Technical Challenge]] — Cumulative 3.0-hour final evaluation: legacy code review, flood emergency logistics challenge, and software engineering ethics essay.
