*ways of working*: how to get Python running, how to read an error
without flinching, how to search like someone who does this for a
living. Each tutorial below teaches one of those skills once, so every
later page can simply link here instead of re-explaining it.

which, per [[Our Classroom Norms]], will be soon, and is fine.
