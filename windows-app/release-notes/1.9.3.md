New in Plantoir 1.9.3

This update brings Windows up to date with what the Mac got in 1.9.1, 1.9.2 and 1.9.3, and adds fixes of its own. Windows goes straight from 1.9.0 to 1.9.3.

BEFORE YOU UPDATE

- Please update. A problem in how a course's name was passed to Claude and Codex is fixed in this version. A course named with symbols such as & or % now reaches the assistant exactly as you wrote it. This affects Revise With and the new Fix with buttons.
- Deploy again each section that has a GeoGebra sketch written as typed commands (sliders, functions, points), or a text block that wraps its long lines. A site already online keeps the fault until you do. Before, such a sketch showed as a dark box whose sliders could not be dragged, and the copy button on a wrapping text block copied nothing. A sketch that only opens a GeoGebra file was not affected.
- If you have a deploy set to run on its own in the next few minutes, wait until it has run before you update.

NEW

- A Problems tab for each section. Every problem a preview or a deploy finds, such as a problem in the course folder or a diagram that could not be drawn, is listed in one table on the section's Problems tab: tick, kind, page, what is wrong, and when it was first and last found, sortable, with the repair in the row. The section shows a warning in the sidebar until its own next build is clean, and after a build that found something new, one message offers to show the list. This replaces the box that listed every folder problem after every build.
- Fix with Claude... and Fix with Codex... Tick problems on the Problems tab and hand them to Claude Code or Codex, which opens on the course with each page named and what to read first. Each button appears only when that assistant is installed on this PC.
- New courses deploy to Cloudflare Pages unless you choose otherwise, listed first as the usual choice. Courses you already have keep deploying where they do now. Choosing Netlify shows a short note: accounts made since September 2025 have a monthly allowance that every deploy uses, and running out pauses every site on the account. A course can now be made and previewed before you have entered its Cloudflare Account ID; Plantoir asks for it at the first deploy, with an Open Settings... button.

IMPROVED

- At Deploy, a ticked class means deployed. Every class dated after the next class starts ticked, and what is ticked goes out; a class you untick is not deployed and is hidden first, with a backup and Undo Last Change as for any hiding. Publish Pages no longer asks about classes dated later.
- Coming back to a section part way through its deploy shows that deploy still running, with Deploy unavailable, instead of a blank console and a Deploy button that could start a second one.
- A saved Netlify or Cloudflare key is no longer thrown away just because the PC could not reach the service. It is cleared only when the service itself refuses it, and a key that Cloudflare refuses is now explained in plain words.
- Deploying to a folder after an update builds the site again first, so the new version's look reaches it. Netlify and Cloudflare already did.
- Typing deploy.bat with no destination now deploys where the course's settings say, every destination in turn.
- A tick box beside a task sits level with its words, on screen and on paper.
- The assistant can no longer go round in circles: if it keeps looking things up without answering, it stops after a few tries, changes nothing, and says so. When Obsidian is not on this PC, or could not be opened, Open in Obsidian says so plainly.
- When Claude or Codex is installed as a program, its window now closes by itself when the session ends instead of leaving a prompt behind, and if it cannot start, Plantoir says so instead of a window flashing away.
- Security and reliability. Several of the parts Plantoir carries to build and deploy your sites were brought up to date, past known weaknesses in the older versions. Your sites look the same.
- Updating with a preview open no longer breaks the install. When Plantoir updates itself, it closes the preview and waits up to ten minutes for a build or a deploy to finish; if one is still running after that, it leaves the old version exactly as it was and offers the update again later. An install you run by hand closes a preview too, and if a build or a deploy is still running it asks you to try again or cancel.

FIXED

- GeoGebra sketches written as typed commands now draw and respond as they should (see Before you update).
- The copy button now works on a text block that wraps its long lines (see Before you update).
- The assistant on this PC is back. The 1.9.0 installer left out a part the small and larger assistants need, so a PC that first got Plantoir at 1.9.0 had no assistant to use.
