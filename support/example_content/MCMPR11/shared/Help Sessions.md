## Extra help

| When | Where |
| --- | --- |

| Thursday, after school until 4:15 | Room 204 |

Drop in — no appointment, no need to tell me first. Bring the specific
thing you are stuck on: one error message beats "my code doesn't work".
Project time counts too.

> [!tip] Prepare before arriving
> Before you walk in, make sure you know exactly what your code currently does, what you *expected* it to do, and the exact input that caused the difference.

If your program runs but does the wrong thing, bring the input you gave
it and what you expected instead. That pair is usually the whole
diagnosis.
