In pairs, then swapped: the conversation every manager dreads and most
handle badly.

## The setup

Each pair gets a short employee file — a mixed year, with genuine
strengths and one real problem. You will run the annual conversation.
Then you swap roles and run a different file, so everyone sits on both
sides.

Your observer's notes are material for you to write from, never a
verdict on you: nobody in this room marks anybody, and what an observer
writes changes no one's mark — see [[How Marks Work]].

Ten minutes each way. A third student observes and takes notes against
the criteria below.

## What the observer is watching for

| Criterion | What a strong version looks like |
| --- | --- |
| Opening | The employee speaks first, and is genuinely asked |
| Evidence | Specific work, specific dates — not impressions |
| The hard part | Said clearly, once, without padding either side of it |
| Listening | The manager changes something after hearing the employee |
| Ending | One agreed action, with a date |

## The debrief

1. Where did the manager soften the hard part until it disappeared? Play
   that back — it is the most common failure in the room.
2. Which appraisal method were you effectively using, and did the file
   support it? See [[Appraisal Methods]].
3. What did the employee know that the manager did not? What in
   [[Performance Appraisal]] would have surfaced it earlier?
4. If pay were attached to this conversation, what would have changed
   about it?

> [!tip] The sentence to practise
> "Here is what I saw, here is the effect it had, and here is what I need
> instead." Say it aloud twice before the conversation. Managers who
> rehearse that one sentence stop burying it.
