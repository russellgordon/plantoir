Grade 11 asked whether your program works. This year the questions get
harder and more interesting: does it model the problem honestly, can
you defend the algorithm you chose, and can somebody else keep it
alive after you have gone. Every page here ends with the curriculum
expectations it serves, and nearly every one points at a practice set
in [[Exercises/index|Exercises]] and a complete working program in
[[Programs/index|Programs]].

Read the idea, then go build something with it — for somebody.
