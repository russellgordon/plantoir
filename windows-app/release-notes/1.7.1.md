New in Plantoir 1.7.1

This update is for Windows only, and brings Windows up to date with everything the Mac got in 1.5.0, 1.6.0, 1.7.0 and 1.7.1.

A menu bar now runs across the top of the window. Everything you can do to a course or section is in it, greyed out when it cannot be done right now, with keyboard shortcuts shown beside the items. File > Open Recent lists the working folders you have opened. The things you used to ask the assistant for are in the Section menu too: Publish Pages, Hide Pages, Publish Class for a Date, Rebuild Preview, Undo Last Change, Add Next Class, Re-date Classes, Make Room for Classes and Class Dates. Each shows you what it will do before it does it.

File > Settings is now one window, with Assistant, Deploying and Preview. Your Cloudflare Account ID lives in Deploying and nowhere else; course settings and the New Course panel show it, with a button to open Settings. Help > Plantoir Help (F1) opens plantoir.app.

When you deploy, Plantoir asks about class pages students can already see that are dated after your next class. You can hide the ones you tick, or keep them all. Tomorrow's class, published the evening before, is never asked about.

Preview can pick up where you left off. In File > Settings > Preview, choose whether Preview opens your site's front page or the page you were last reading in that section. Hold Alt to get the other choice for one press. The Preview button and Section menu always say what will happen. Nothing changes unless you ask for it.

A page can now print as a handout. Course Settings has a Printing section, and Print in the preview opens the page in your web browser, ready to print. You can draw diagrams in your notes and add graphs of functions that students can drag and zoom. Both print whole, in black on white. Claude and Codex are told how to write these pages: on request, Plantoir writes a short guide into your working folder, and asks before adding to a CLAUDE.md or AGENTS.md you already keep there.

Windows also follows its own conventions more closely. Escape closes every window and is never trapped, a button that cannot be pressed never looks like the main one, and the Delete key (or the minus button) removes the course, section or backup you have selected, after asking. All Backups can be sorted and has a right-click menu. Dialog titles are clearer, and the smallest text is a little bigger. Right-click a course or section for Revise With, then Claude, Codex or the local assistant.

Fixed: if you set a scheduled deploy again while an earlier run is still working, the new one now waits its turn instead of being lost. A scheduled deploy also brings the folder's tools up to date by itself first. Closing Plantoir while a folder is being got ready now waits for it to finish, then quits. When you hide a page, the preview now rebuilds, as it does when you publish one. When Claude or Codex's preview cannot be built, the answer now says why in a sentence. A failed build is no longer blamed on Netlify just because the number 429 appeared in its output.
