Some skills in a newsroom are not concepts and not assignments — they
are *ways of working*: how to file a story so an editor can find it,
how to ask for consent properly, how to make sure a shoot can never
be lost. Each tutorial below teaches one of those skills once, so
every later page can simply link here instead of re-explaining it.
