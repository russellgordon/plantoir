This site is the course: the schedule, the methods, the safety, and the
expectations behind all of it.

| Folder | Holds | You will use it |
| --- | --- | --- |
| **All Classes** | One page per period — what we are doing and where | Every day |
| **Concepts** | The ideas, stated cleanly | After the class that met one |
| **Techniques** | Tools, measurement, drawings, construction | Before and during shop work |
| **Safety** | PPE, hazards, safe practice, and the law | Before every practical day |
| **Growing** | Propagation, soils, watering, planting, harvest | Whenever you are on the bench or the site |
| **Portfolios** | Your evidence file and skills record | All semester |
| **Tasks** | Assessed work, with the criteria | Whenever something is due |
| **Tutorials** | Using the site, and writing a work record | The first time you need one |
| **Setup** | How the course runs | Week one |
| **Style** | How the site works | Now |

## How the pieces connect

Class pages are the spine, and they say where we are working — shop,
woodlot, shoreline, farm, or classroom. The backlinks at the bottom of a
page show which classes used it.

Content pages end with a **Curriculum connection**: the Ministry
expectations that page addresses, in the Ministry's own words. The site
builds a coverage map from those links.

## Two conventions

- **Safety pages come before the work, not after it.** If a class page
  links one, read it that morning.
- **The newest class is on the section landing page.** If you were away,
  start there.
