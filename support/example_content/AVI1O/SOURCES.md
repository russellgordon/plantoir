The museum's terms, read the same day at https://www.artic.edu/image-licensing:

How each was checked: the artwork's own page on artic.edu was fetched on the
date shown and read for the label under its image; the museum's public
record for the work (api.artic.edu) was read for "is_public_domain: true".
Each file was downloaded from the museum's own image service
(www.artic.edu/iiif/2/, 843 pixels wide, the size the museum asks for) and
was looked at before the words describing it were written.
