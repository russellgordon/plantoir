## Three things worth knowing

**Links go both ways.** At the foot of most pages is a list of the pages
that link to it. That is the fastest way to find which class used an
idea, and the fastest way to see how a source has been used more than
once.

**Search is fast.** Press `Ctrl`+`K` — or `Cmd`+`K` — and type. It
searches inside pages, not only titles, so a name, a year, or a phrase
from a document will find it.

**A folded block hides something.** A line with a small arrow beside it
opens when you click. It usually holds a check-yourself question or a
worked example, and it is folded deliberately. Try answering before you
open it; reading an answer feels like learning and is not.

> [!note] Checkboxes here are yours
> The `- [ ]` lists on these pages can be ticked as you go. Your browser
> keeps the ticks on this computer; nothing is sent anywhere, and the site
> does not know who you are.

## If a link does not work yet

A class page appears on the day we reach it. If tomorrow's page is
missing, that is because tomorrow has not happened yet — not because
something is broken. The same is true of a task page for a unit we have
not started. Ask if you are unsure.
