Read this first, before any paper.

## Identifiers only

Papers are named by identifier (`Student A`), never by a name. If a name
can be seen anywhere on a paper, do not repeat it: write
"NAME VISIBLE page N" in that paper's `checks` and tell the teacher the
identifier and the page. Marking itself is the `plantoir-marking` skill's
work, and its rules come first.

## What is here

- `answers.json`: every mark on the test, for both versions, in the kit
  format (`FORMAT.md` in the `plantoir-test-authoring` skill). 16 points:
  K 4, T 6, C 3, A 3.
- `marks-template.json`: one empty marks record. Copy it once per paper.
- `../Marking Guide.pdf`: the same marks for a person to read, with the
  misconception behind every wrong option in Part A.
- `../Version A.pdf`, `../Version B.pdf` and their solutions.

## How this test is marked

- One mark per point. Check the version at the top of the paper first, and
  mark against that version's answers.
- Follow-through: `B1.3` follows through from `B1.1` and `B1.2`, and
  `D1.3` from `D1.2`. A slip loses its own point only.
- An answer in `accept` earns the mark. An answer that is right in a way
  the kit does not list is the teacher's call: earn it provisionally, say
  why in `note`, and list it in `checks`.
- Every mark is a draft for the teacher to decide.
