Working reference implementations and demonstration scripts — small,
complete programs you can read start to finish, run, and change yourself.
Each one pairs with a concept you've already met in class.

- [[Pacific Route Simulator]] — Branching decisions from BC Ferries wind and sailing conditions.
- [[Salish Sea Marine Monitor]] — Scanning a sequence of sensor readings for anomalies.
- [[Community Lexicon Search]] — A searchable dictionary for an Indigenous-language lexicon.
- [[Newcomer Services Directory]] — Matching a language to a settlement service line.
- [[Wildfire Hazard Analyzer]] — Validating input safely and computing a risk rating from it.
